# CoPilot RD S.R.L.

Repositorio independiente de desarrollo de CoPilot RD S.R.L.

## Objetivo

Desarrollar, corregir, asegurar y documentar la plataforma antes de su integración con CoPilotRD.

## Estructura

- backend/: servicios y API
- frontend/: interfaz web
- config/: configuración del proyecto
- docs/: documentación técnica

## Seguridad

El proyecto debe superar pruebas de autenticación, autorización, dependencias y configuración antes de publicarse en producción.

## Estado

## Integración

La integración con CoPilotRD se realizará posteriormente, una vez completadas las pruebas.
